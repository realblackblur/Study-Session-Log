# Study Session Log

## Goal
A study tracker that helps students track their study time by subject and save completed study sessions.

## Features
- Start and pause the study timer.
- Reset the current timer.
- Enter a subject name and save a study session.
- View saved study sessions and their durations.

## How to Run
```bash
npm install
npm run dev
```

## Tech Stack
- React
- TypeScript
- Vite
