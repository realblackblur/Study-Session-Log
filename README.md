# Study Session Tracker

A simple study session tracking application built with React and TypeScript. It helps students track how much time they spend studying different subjects.

## Features

- **Start / Pause Timer:** Start the timer and pause it whenever needed.
- **Resume Timer:** Continue a paused session without losing elapsed time.
- **Reset Timer:** Reset the timer to `00:00:00`.
- **Subject Input:** Enter the subject you are studying.
- **Save Sessions:** Save completed study sessions with their subject names and durations.
- **Session History:** View all previously saved study sessions.
- **Time Formatting:** Display elapsed time in `HH:MM:SS` format.
- **Input Validation:** Prevent saving sessions with an empty subject or zero duration.
- **Empty State:** Display a message when no sessions have been saved.

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Git & GitHub

## Purpose

This project was built as a hands-on learning exercise to practice React, TypeScript, component architecture, state management, props, event handling, and React Hooks.

The application was developed incrementally by breaking the project into smaller features and implementing them step by step.
